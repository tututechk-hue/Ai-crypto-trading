# AI Crypto Trading - Initial Scaffold

This repository contains the initial scaffold for the AI Crypto Trading project: backend (Node/Express/TypeScript), frontend (React/TypeScript/Vite), Prisma + SQLite, Docker and Render deploy configuration.

This initial commit focuses on a safe, minimal, production-oriented scaffold. Subsequent commits will add the full trading engine, AI learning pipeline, TradingView charts, admin panel, and the rest of the features requested.

See README.md for full setup and deployment instructions.
